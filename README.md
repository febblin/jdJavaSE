# jdJavaSE — Java Runtime для Sony PlayStation Portable

**jdJavaSE** — это кастомная виртуальная машина Java (JVM), написанная специально для Sony PlayStation Portable (PSP). 

## 💡 Философия
> Разработка на PSP перестаёт быть разработкой на PSP. Она становится разработкой на Java с PSP-таргетом.

Java-программист не должен переучиваться, чтобы запустить свою игру на портативной консоли. Вы пишете код в привычной среде (AWT, `ArrayList`, `MathUtils`), а jdJavaSE транслирует его в железо PSP, используя VFPU (векторный сопроцессор) и Graphics Engine (GE) напрямую.

## 🚀 Что умеет jdJavaSE (v5.6)

*   **Полноценный AWT:** `Frame`, `Graphics`, `BufferedImage`, `drawImage`, `fillRect` (с поддержкой **альфа-канала**), `drawString`, `fillPolygon`.
*   **Стандартные коллекции:** `ArrayList`, `HashMap` (реализованы нативно).
*   **Математика на VFPU:** `MathUtils`, `Matrix4`, `Vector2/3/4` используют ассемблерные вставки VFPU.
*   **Ввод-вывод:** Чтение файлов (`FileInputStream`), парсинг JSON (`JsonParser`).
*   **Звук:** `javax.sound.sampled` (`AudioSystem`, `Clip`). Поддержка WAV и **MP3 (через аппаратный Media Engine)**. Многопоточность PSP для фоновой музыки.
*   **3D-рендер:** Трансформация вершин, освещение Ламберта, Z-сортировка и нативный батчинг полигонов.

## 📦 Установка и запуск

1. Скачайте архив в разделе **Releases**.
2. Распакуйте папку в `ms0:/PSP/GAME/` на вашей PSP (или в папку PPSSPP).
3. Запустите `EBOOT.PBP`.
4. Внутри уже лежат тестовые приложения (BunnyMark, TestSuit).

> **Важно:** Исходный код на данный момент закрыт. Репозиторий предоставляет только скомпилированные бинарные файлы для демонстрации возможностей виртуальной машины.

## 🎮 Первая игра
В качестве доказательства концепции на этой VM создана игра **Wolf_in3D** — полноценный 3D-шутер с навигацией врагов, звуком и сюжетом, работающий полностью на Java.
